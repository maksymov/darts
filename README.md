# Дартс — ваш домашний клуб

Основная версия сайта остаётся на главной странице. Новая версия с режимом ТВ, комментатором и карточкой матча доступна по адресу `/beta/` и открывается кнопкой **«Бета»** в шапке основной версии. Обе версии — статические приложения: без сборки, регистрации и серверного хранения партий.

## Запуск

Из корня проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8000 для основной версии или http://127.0.0.1:8000/beta/ для бета-версии. На localhost service worker не регистрируется, поэтому изменения видны после перезагрузки. На основном домене версии кэшируются раздельно.

## Телевизор, клавиатура и сенсорный экран

Кнопка **«Режим ТВ»** увеличивает элементы и включает постоянное выделение фокуса. При 1280×720 табло X01 для двух игроков и панель ввода помещаются на одном экране. Для большого состава и длинной истории допускается прокрутка; фокус автоматически прокручивает выбранный элемент в видимую область.

- Стрелки перемещают фокус в направлении расположения элементов, включая экранные клавиатуры.
- OK / Enter нажимает кнопку. Enter в поле очков сохраняет ход.
- Цифры клавиатуры вводят очки; экранная цифровая панель доступна всегда.
- Backspace удаляет цифру. Escape / доступная странице кнопка Back закрывает окно; в игре сначала очищает незаписанный ввод, затем возвращает в главное меню.
- Tab / Shift+Tab поддерживают обычный обход элементов. В открытом окне фокус остаётся внутри него; при закрытии возвращается к исходной кнопке.
- Имя можно оставить стандартным, ввести обычной клавиатурой или набрать экранными буквами. В ТВ-режиме экранная клавиатура открыта сразу.
- Режим ТВ, тема и включение реакций сохраняются в этом браузере.

Поддержаны стандартные клавиши и известные коды Back для [Samsung](https://developer.samsung.com/smarttv/develop/guides/user-interaction/remote-control.html) и [LG webOS](https://webostv.developer.lge.com/develop/guides/back-button). Встроенный браузер телевизора может перехватывать Back или использовать стрелки для своего указателя: поведение конкретного устройства нужно проверить на нём. Это веб-страница, не установленное нативное ТВ-приложение.

## Партии и правила

- Текущая партия хранится в `localStorage` под ключом `darts.v2`.
- При первом запуске обновления читаются прежние ключи `players`, `circles`, `curr_game`, `total_score`. Старые ключи не удаляются. Последовательность ходов восстанавливается из старой таблицы; её пустые нули не позволяют достоверно отличить незаписанный ход от промаха в конце последнего круга. Сумма очков сохраняется; при необходимости очередь можно поправить отменой/записью хода.
- Новый ход автоматически передаёт очередь. «Отменить последний ход» восстанавливает очки и очередь. Записи истории редактируются.
- Сумма хода X01 — целое число от 0 до 180. Перебор не уменьшает остаток; победа — ровно ноль. Как и в исходном расчёте, обязательное финальное удвоение автоматически не проверяется.
- В игре по секторам попадание закрывает текущую цель. Игрок может закрыть несколько секторов за подход; отдельная кнопка «Передать ход» переключает очередь. Цели: 1–20, 25, 50; попадание в 50 завершает партию.
- Начало новой партии поверх незавершённой, сброс и удаление игрока требуют подтверждения внутри приложения.

## Ишак-комментатор и карточка матча

Ишак реагирует на победу, перебор, 180 и другие крупные наборы, смену лидера, личный рекорд партии, близкий финиш и промахи. В режиме секторов он отмечает этапы пути и выход к центру. Обычные реплики обновляются не чаще одного раза за шесть секунд; победа, 180 и перебор имеют приоритет. Реплики не перемещают фокус и не перекрывают кнопки. В настройках «Ишак-комментатор» выключается отдельно от анимаций; выбор сохраняется локально. При `prefers-reduced-motion` текст остаётся доступен без анимации.

После победы кнопка **«Карточка матча»** открывает предпросмотр: победитель, режим, дата начала партии, все результаты на момент финиша и шуточная награда. Для X01 указан лучший засчитанный ход за матч; переборы исключаются, при равенстве сохраняются имена всех рекордсменов. Для секторов показаны закрытые цели. Награда рассчитывается из статистики победителя. После исправления истории карточка собирается заново, после отмены победного хода она недоступна до нового финиша.

- **Сохранить PNG** — локальное изображение шириной 1080 px, высота увеличивается для большого числа игроков. Один и тот же PNG используется для просмотра, скачивания и отправки.
- **Отправить…** — системное меню устройства, если браузер поддерживает отправку файлов. Иначе доступно сохранение PNG с подсказкой отправить его из файлов/галереи. Файл подготавливается до нажатия, чтобы сохранить требуемую [Web Share API активацию пользователя](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share).
- Всё формируется на устройстве, без загрузки результатов на сервер. На телевизоре можно открыть карточку и дойти до её действий стрелками; доступность скачивания и системной отправки зависит от браузера телевизора.

## Файлы и проверки

- `index.html` — основная версия с переходом на бета-версию.
- `beta/index.html` — оболочка бета-версии.
- `beta/static/` — бета-стили, игровая логика и ресурсы.
- `sw.js` и `beta/sw.js` — независимые кэши основной и бета-версии. При обновлении ресурсов соответствующей версии меняйте её `CACHE_NAME`.

Регрессионные проверки без сторонних зависимостей, нужен Node.js:

```sh
node tests/game.test.cjs
node tests/match-extras.test.cjs
```

Проверяются обычный ход, перебор, победа, отмена, неверный ввод, пересчёт истории, секторы и перенос старых партий. Браузерная проверка включает стрелки/Enter, экранную клавиатуру, обе темы и мобильную/планшетную/ТВ-раскладки. Физический телевизор не использовался.

Дополнительно проверяются приоритет победной реплики, переборы, ничьи по лучшему ходу, смена лидера, награды после исправлений, этапы секторов и отсутствие изменений игрового состояния при построении карточки. В браузере проверены скачанный PNG 1080×1350, мобильный предпросмотр, выключатель комментатора и фокус с пульта. Отправка реальному получателю не выполнялась.
